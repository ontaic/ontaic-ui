Introduction

Ontaic is a Bi-Directional Compiler & State Runtime for Python that compiles Python code into static UI schemas and a Rust WASM runtime for instant browser-side DOM mutations.

Why Ontaic?
  • 0ms DOM Updates - Rust WASM directly patches the DOM
  • Pure Python - No JavaScript or TypeScript needed
  • Static Output - Deploy anywhere (CDN, S3, GitHub Pages)
  • 430+ Components - Everything from data grids to 3D viewers

Installation

CLI (Rust)

cargo install ontaic-cli

Python SDK

pip install ontaic

From Source

git clone https://github.com/ontaic/ontaic-ui.git
cd ontaic-ui
cargo build --release
cd python
pip install -e .

Quick Start

1. Create a new project

ontaic init my-app
cd my-app

2. Create your first component

# src/components/counter.py
from ontaic import *

class Counter(Component):
    count: int = 0
    
    def render(self):
        return Container(
            Heading(f"Count: {self.count}"),
            Flex(
                Button("Increment", on_click=self.count.add(1)),
                Button("Decrement", on_click=self.count.sub(1)),
                gap="1rem"
            )
        )

3. Start development

ontaic dev

Open http://localhost:3000 to see your app.

Components

Components are the building blocks of your UI. They inherit from the Component class and implement a render() method.

from ontaic import *

class MyComponent(Component):
    # State fields
    name: str = "World"
    count: int = 0
    
    def render(self):
        return Container(
            Heading(f"Hello, {self.name}!"),
            Text(f"Count: {self.count}"),
            Button("Click me", on_click=self.count.add(1))
        )

State Management

State is automatically tracked and updates the UI when changed.

Local State

class Counter(Component):
    count: int = 0  # Local state
    
    def increment(self):
        self.count += 1

Persistent State

from ontaic import *

# State persists across sessions
user_state = PersistentState("user", {
    "name": "",
    "isLoggedIn": False
})

Events

Handle user interactions with event handlers.

class Form(Component):
    name: str = ""
    
    def handle_submit(self):
        print(f"Submitted: {self.name}")
    
    def render(self):
        return Form(
            Input(
                value=self.name,
                on_change=self.name.set
            ),
            Button("Submit", on_click=self.handle_submit)
        )

Layouts

Use layout components to structure your UI.

from ontaic import *

# Flex layout
Flex(
    Text("Item 1"),
    Text("Item 2"),
    Text("Item 3"),
    direction="row",
    gap="1rem",
    justify="center"
)

# Grid layout
Grid(
    Card(Text("Card 1")),
    Card(Text("Card 2")),
    Card(Text("Card 3")),
    columns=3,
    gap="1.5rem"
)

# Stack layout
Stack(
    Heading("Title"),
    Text("Description"),
    Button("Action"),
    spacing="1rem"
)

ontaic init

Initialize a new Ontaic project.

ontaic init [project-name]

Creates a new project directory with the following structure:

  • ontaic.json - Project configuration
  • src/ - Source directory
  • public/ - Static assets

ontaic add

Add a component from the registry.

ontaic add [component-name]

Fetches the component from GitHub and adds it to your project.

ontaic dev

Start the development server with hot-reload.

ontaic dev [--port 3000]

Features:

  • Hot-reload on file changes
  • Automatic WASM compilation
  • Error overlay
  • Live preview

ontaic build

Build the project for production.

ontaic build [--output dist]

Outputs:

  • schema.json - UI schema
  • ontaic_bg.wasm - WASM binary (<100KB)
  • index.html - Entry point

Compiler API

The compiler transforms Python code into JSON schemas.

from ontaic.compiler import OntaicCompiler

compiler = OntaicCompiler()

# Compile a file
schema = compiler.compile_file("src/components/counter.py")

# Compile a directory
schemas = compiler.compile_directory("src/components/")

# Save schema
compiler.save_schema(schema, "dist/schema.json")

WASM Runtime

The Rust WASM runtime handles state and DOM updates.

// State management
let state = StateStore::new();
state.set("count", 0);
state.on_change(|key, value| {
    // Apply DOM patches
    patch_dom(PatchOp::SetText {
        id: "counter".to_string(),
        text: value.to_string(),
    });
});

// DOM patching
fn patch_dom(op: PatchOp) {
    match op {
        PatchOp::SetText { id, text } => {
            document.get_element_by_id(&id)
                .set_text_content(&text);
        }
        PatchOp::SetAttr { id, key, val } => {
            document.get_element_by_id(&id)
                .set_attribute(&key, &val);
        }
        // ... more operations
    }
}
