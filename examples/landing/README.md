# Landing — what people get by default

This is a **real-defaults preview**. No custom theme.
Every component block is actual SDK `render()` / `to_html()` output.

## Preview

`index.html` was generated by `build.py` from `app.py`.

Open it:

```powershell
# Option 1 — just open the file
start examples\landing\index.html

# Option 2 — serve locally (recommended, Chart.js + Tailwind CDN need http)
python -m http.server 8000
# open http://localhost:8000/examples/landing/
```

## Regenerate after SDK changes

```powershell
cd examples\landing
python build.py
```

## What is shown

- `Navbar(brand="⚡ Ontaic", ...).render()` — top nav
- `Table(..., striped=True).render()` — comparison table
- `BarChart(...).render()` — Chart.js defaults
- `FormField / Select / Checkbox` — form defaults
- `Alert / Badge / Avatar` — extra_components defaults
- `DataGrid.to_html()`, `Calendar.to_html()`, `KanbanBoard.to_html()`,
  `Timeline.to_html()`, `QRCode.to_html()`, `MediaPlayer.to_html()`
- `Accordion(items=[...]).render()` — FAQ
- All `*_CSS` blocks inlined in `<style>`
